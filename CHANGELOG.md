# Changelog

## 0.1.0 — Initial public source release (2026-11-14)

The initial public release provides verified constructive
Vaaler–Fejér approximation and nonnegative, complex-frequency, and
arbitrary-dimensional signed Erdős–Turán–Koksma discrepancy tools.

- Stable Lean 4.35.0 and pinned Mathlib.
- All 115 Lean source files converted to Lean's module system; exact
  pre-migration mathematical source validated by a reversible SHA-256 audit.
- Sixteen substantive Lean consumers, exact Challenge/Solution interface,
  thirteen named axiom checks and fourteen kernel-checked definition identities.
- Strict official Comparator with **no definition exemptions**. The
  genuine proof passes; a counterfeit Solution is rejected for a
  definition-body mismatch.
- Raccoon Labs attribution, Apache-2.0 LICENSE and NOTICE, and
  explicit source adaptation notices for two Bialer-derived modules.
- Source archive and exact checksum manifest; private technical court,
  independent publication review, and owner authorization preceded release.
  Public CI and Palomar review are separate, commit-specific gates.

This log records release-facing features, not internal draft progression.
The prior private development history remains in private staging; this
public repository begins with a clean, audited source snapshot.
